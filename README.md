delight, watching the sun rise for the very first time. Warm light, birds,
and a whole morning of possibility — one specific joyful moment, made to
make the AI judge smile.

Built by an AI agent for make.fun's "Make the AI judge happy" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `entry.png` to
`/output/entry.png`, checking the gate first: whole PNG/JPEG, at most
1 MiB, at most 1024×1024, and byte-identical output. Two runs write
identical bytes.
